## ✨ Key Features
- **🧠 Interactive Neural Background**: Custom vanilla canvas-based particle network reacting to mouse movements.
- **⚡ Typing Effect Hero**: Dynamic typewriter effect cycling through core automation offerings.
- **🔄 Interactive Services Flip-cards**: 3D card-flip animations highlighting 6 main services.
- **🏭 Infinite Industries Marquee**: Smooth infinite scrolling marquee featuring served business sectors (pauses on hover).
- **🤖 Live Simulated Terminal**: Mimics a running AI automation engine processing real-time tasks.
- **📈 ROI Savings Calculator**: High-fidelity, user-friendly interactive sliders calculating team hours, costs, and full-time employee equivalents.
- **💬 Demo AI Chatbot**: Interactive, floating chatbot responding dynamically to user keywords with smart delays.
- **📝 Validated Contact Form**: Comprehensive client-side form validation with real-time field status indication.
- **📱 Fully Responsive**: Custom mobile-first layouts designed to look polished at 360px (mobile), 768px (tablet), and 1440px (desktop).

## 🛠️ Built With
- Pure HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Grid Layouts, Keyframes, Glassmorphism)
- Vanilla JavaScript (Canvas Engine, Observer Triggers, Calculations)
- Google Fonts (Plus Jakarta Sans, Inter, JetBrains Mono)
- Zero external frameworks, libraries, or page builders.
